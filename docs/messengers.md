# Мессенджеры: Telegram, WhatsApp, ВКонтакте

Harvey умеет работать с мессенджерами тремя способами. Каждый включается отдельно.

| | Что делает | Кто отправляет |
|---|---|---|
| **1. Первые сообщения** | Для компаний, у которых на сайте есть ссылка на Telegram, WhatsApp или VK, Harvey пишет короткое первое сообщение и один повтор | **Вы**, со своего аккаунта, в один клик |
| **2. Диалоги с ботом** | Читает, что люди пишут вашему Telegram-боту, сообществу ВК или номеру WhatsApp Business, и готовит ответы | Harvey, после вашего одобрения (или сам, в режиме автопилота) |
| **3. Контакты** | Находит на сайтах компаний ссылки t.me, wa.me, vk.com | — |

Сообщения пишутся по-русски.

## Почему первое сообщение отправляете вы, а не Harvey

Автоматическая отправка с личного аккаунта Telegram, WhatsApp или ВК нарушает правила всех трёх платформ, и такие аккаунты быстро ограничивают. Кроме того, ст. 18 закона «О рекламе» требует предварительного согласия на рекламу по сетям электросвязи, включая мессенджеры. Поэтому Harvey делает всю работу (находит компании, читает сайт, пишет персональное сообщение), а отправку оставляет вам: кнопка «Открыть» открывает чат с уже вставленным текстом, и вы нажимаете «Отправить» сами.

Первое сообщение написано как вопрос о задаче бизнеса, а не как реклама, и всегда заканчивается простым способом отказаться. Отказ соблюдается сразу. Это снижает риски, но не заменяет консультацию юриста.

## Быстрый старт

### 1. Включить

В `harvey.local.yaml` (или `harvey.yaml`, если вы не обучали Harvey):

```yaml
channels:
  messengers:
    enabled: true
```

### 2. Разрешить сбор контактов

```bash
harvey signals --confirm MESSENGER_TELEGRAM,MESSENGER_WHATSAPP,MESSENGER_VK
```

Или на вкладке **Signals** в дашборде. После этого профилирование (`harvey profile` или каждый цикл `harvey run`) записывает, какие мессенджеры компания указала на своём сайте. Проверяется главная страница, а если там ничего нет — страница контактов (`/contacts`, `/kontakty` и т.п.).

Что считается контактом:

- **Telegram:** `t.me/имя`, `t.me/+79990001122`, `tg://resolve?domain=имя`. Боты (имя на `bot`), ссылки-приглашения в группы и кнопки «поделиться» не считаются.
- **WhatsApp:** `wa.me/79990001122`, `api.whatsapp.com/send?phone=…`, короткие ссылки WhatsApp Business `wa.me/message/…`. **Просто номер телефона на сайте не считается**: на странице не сказано, что у этого номера есть WhatsApp.
- **VK:** страница или сообщество (`vk.com/имя`, `vk.com/club123`, `vk.me/имя`). Посты, видео и кнопки «поделиться» не считаются.

### 3. Отправлять

Запустите `harvey run` и откройте `harvey dashboard` → вкладка **Messengers**.

Для каждой компании там будет карточка с сообщением. Текст можно поправить прямо в карточке.

- **Открыть в Telegram / WhatsApp / ВКонтакте**: проверяет сообщение, копирует текст в буфер обмена и открывает чат. В WhatsApp и в Telegram (по имени пользователя) текст уже стоит в поле ввода; в VK и в Telegram по номеру его нужно вставить (Ctrl+V).
- **Отправил**: отметьте после отправки. Через `followup_days` дней (по умолчанию 3) в очереди появится повтор.
- **Ответили…**: если вам ответили. Повтор отменяется. Вставьте их ответ, и Harvey подготовит черновик, что написать дальше; он появится в разделе «Диалоги» после следующего цикла. Его вы копируете и отправляете сами.
- **Пропустить**: не писать этой компании.

Пока сообщение нарушает правила (запрещённые фразы, больше одной ссылки, незаполненный шаблон, компания в списке `do_not_contact`), кнопка «Открыть» не сработает и покажет причину.

## Диалоги через бота

Здесь первым пишет человек, поэтому Harvey может отвечать сам: так устроены все три платформы.

### Telegram-бот

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. В `.env`: `TELEGRAM_BOT_TOKEN=…`
3. В конфиге: `channels.messengers.telegram.enabled: true`
4. Проверьте: `harvey messengers test`

Публичный адрес не нужен: Harvey сам забирает новые сообщения каждый цикл. Когда человек нажимает Start, бот один раз отправляет приветствие (`telegram.welcome`, без участия модели). Ссылку на бота можно ставить в подпись письма, на сайт или в визитку.

### Сообщество ВКонтакте

1. Сообщество → Управление → Работа с API → Ключи доступа → создайте ключ с доступом к **сообщениям сообщества**.
2. В том же разделе включите сообщения сообщества.
3. В `.env`: `VK_GROUP_TOKEN=…`
4. В конфиге: `channels.messengers.vk.enabled: true`
5. `harvey messengers test`

Harvey читает диалоги, которые ВК отмечает как неотвеченные. Сообщество может писать только тем, кто написал ему сам или разрешил сообщения.

### WhatsApp Business (Meta Cloud API)

Это официальный API Meta, а не обычный WhatsApp. Нужны приложение в [Meta for Developers](https://developers.facebook.com/), номер, подключённый к WhatsApp Business Platform, и верифицированный бизнес. **Для компаний из России подключение может быть недоступно**: Meta ограничивает работу с РФ.

1. В `.env`:
   - `WHATSAPP_TOKEN`: постоянный токен системного пользователя;
   - `WHATSAPP_APP_SECRET`: секрет приложения (App settings → Basic);
   - `WHATSAPP_VERIFY_TOKEN`: любая строка, которую вы придумаете (её же укажете в Meta).
2. В конфиге:
   ```yaml
   channels:
     messengers:
       whatsapp:
         enabled: true
         phone_number_id: "1234567890"   # WhatsApp → API Setup
   ```
3. Запустите приёмник сообщений (webhook):
   ```bash
   harvey messengers whatsapp-webhook --host 127.0.0.1 --port 8787
   ```
   Meta должна достучаться до него по HTTPS, поэтому нужен сервер с доменом и обратным прокси. Пример для Caddy:
   ```
   wa.example.com {
       reverse_proxy 127.0.0.1:8787
   }
   ```
4. В Meta: WhatsApp → Configuration → Webhook: адрес `https://wa.example.com/webhook`, verify token из шага 1, подписка на `messages`.

Каждое входящее уведомление проверяется по подписи `X-Hub-Signature-256` (секрет приложения); без верной подписи ничего не сохраняется. Отвечать свободным текстом WhatsApp разрешает только в течение 24 часов после последнего сообщения человека. Позже нужен одобренный Meta шаблон, а Harvey такие не отправляет: ответ останется в дашборде с объяснением.

### Как Harvey отвечает

Каждый цикл:

1. Забирает новые сообщения.
2. Сначала применяет **жёсткие правила, без модели**:
   - «нет», «стоп», «не пишите», «отпишите», «это спам» и т.п. → больше не пишем, вообще. Все запланированные сообщения этой компании отменяются. Новые сообщения от человека сохраняются для вас, но Harvey на них не отвечает.
   - «юрист», «суд», «жалоба», «РКН», «ФАС», угрозы, а также фото и голосовые без текста → диалог передаётся вам («Нужны вы»).
3. Остальное читает модель: определяет намерение (интерес, вопрос, сомнение, отказ…) и пишет короткий ответ. При отказе Harvey не отвечает и закрывает диалог.
4. Ответ проходит те же проверки, что и первое сообщение.
5. **Режим одобрения** (по умолчанию, `require_approval: true`): ответ ждёт вас на вкладке Messengers. «Одобрить» → уйдёт в следующем цикле.
   **Автопилот** (`require_approval: false`): ответ уходит сам. Ответ со ссылкой на чужой домен или с цитатой внутренних инструкций Harvey всё равно ждёт вас, как и в почте. При обратном включении одобрения всё, что автопилот одобрил и не успел отправить, возвращается вам.

`harvey sending pause` (или кнопка паузы в дашборде) останавливает и отправку в мессенджеры.

## Все настройки

```yaml
channels:
  messengers:
    enabled: false
    cold_drafts: true                # писать первые сообщения
    channel_order: ["telegram", "whatsapp", "vk"]   # куда писать, если контактов несколько
    max_daily_drafts: 20             # сколько первых сообщений писать в день
    max_daily_manual_sends: 30       # сколько первых сообщений дашборд даст открыть в день
    followup_days: 3                 # повтор через N дней; 0 = без повтора
    skip_if_emailed: true            # не писать тем, кому уже ушло письмо
    max_chars: 600                   # максимум знаков в первом сообщении
    opt_out_line: "Если неактуально, напишите «нет», и я больше не побеспокою."
    require_approval: true           # ответы бота ждут вас
    telegram: { enabled: false, welcome: "Здравствуйте! Напишите ваш вопрос, отвечу здесь." }
    vk: { enabled: false }
    whatsapp: { enabled: false, phone_number_id: "" }
```

Строка отказа (`opt_out_line`) обязательно должна просить ответ, который Harvey распознаёт: «нет», «стоп», «не пишите» или «отписаться».

## Как сделать сообщения лучше

- `prompts/messenger_writer.md`: правила первого сообщения и повтора.
- `prompts/messenger_handler.md`: как отвечать в диалоге.
- `skills/messenger_outreach_ru.md`: методичка по переписке в мессенджерах. Правьте её как обычный текст: следующий цикл уже будет её учитывать.

## Где работает Harvey

На вашем компьютере или на сервере, как и всё остальное в Harvey. Для WhatsApp Business нужен сервер с публичным HTTPS-адресом (для webhook). Telegram-боту и сообществу ВК публичный адрес не нужен.

Claude Code должен работать там, где запущен Harvey. Claude официально недоступен в России, поэтому сервер размещают за её пределами.

## Команды

```bash
harvey messengers                  # очередь и диалоги
harvey messengers test             # проверить токены ботов
harvey messengers whatsapp-webhook # приёмник сообщений WhatsApp (за HTTPS-прокси)
```
